# NFT Marketplace — React + Tailwind

Pixel-focused recreation of the supplied NFT marketplace screens.

## Stack
- React + Vite
- Tailwind CSS
- React Router DOM
- Axios service boundary
- Framer Motion
- Lucide React icons

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

The `/public/assets` images are cropped from the reference screenshots supplied in the conversation so the visual artwork matches the provided references. Replace them with the original Figma-exported image assets if you have them for lossless source quality.
